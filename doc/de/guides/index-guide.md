# Index-Leitfaden

## Eine index.jsonc anlegen <a id="create-an-indexjsonc"></a>

- Falls nicht vorhanden:
  - Kopiere `doc/en/templates/index-template.jsonc` nach `index.jsonc`
- Behalte die Felder der Vorlage bei, füge keine eigenen hinzu
- Behalte die Kommentare: Sie sagen, was in welches Feld gehört

## index.jsonc für die Planung nutzen <a id="use-indexjsonc-for-planning"></a>

- Lies die Index-Datei, bevor ein Ticket geplant wird
- Lies bei Bedarf auch die Index-Dateien aller Ocean-Repos
- Entscheide dann, welche Repos das Ticket braucht

## index.jsonc vor jedem Publish aktualisieren <a id="update-indexjsonc-before-each-publish"></a>

- Aktualisiere die Index-Datei vor dem Veröffentlichen jedes Tickets
- Schreibe so kurz und tokensparend wie möglich
- Verwende Stichwörter statt Sätzen
- Aktualisiere geänderte Dateien oder Schnittstellen
