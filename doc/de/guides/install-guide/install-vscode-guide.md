# Vscode installieren

## Vscode installieren <a id="install-vscode"></a>

<https://code.visualstudio.com/download> aufrufen

Herunterladen und installieren

## Erweiterungen installieren <a id="install-extensions"></a>

Beim ersten Öffnen dieses Projekts erscheint die Frage, ob die empfohlenen
Workspace-Erweiterungen installiert werden sollen. Auf `Install` klicken.

Erscheint dieser Schritt nicht:

`Ctrl+Shift+P` drücken.

`Extensions: Show Recommended Extensions` eingeben und `Enter` drücken.

Die empfohlenen Erweiterungen werden angezeigt.

Sicherstellen, dass alle empfohlenen Erweiterungen installiert sind.
