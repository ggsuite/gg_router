# Leitfaden für Leitfäden

- Verwende den Imperativ in Überschriften und Text (wie hier)
- Formuliere die Überschriften so, dass sie zusammen eine Zusammenfassung
  ergeben
- Beschreibe jeden Schritt in einer Zeile
- Formatiere `screen elements`, `commands` und `code` als Code.
- Setze Shell-Befehle in einen bash-Code-Block

```bash
ls -la
```

- Beschreibe Schrittfolgen als Sätze mit einer Leerzeile dazwischen
- Schreibe in kurzen und klaren Sätzen
