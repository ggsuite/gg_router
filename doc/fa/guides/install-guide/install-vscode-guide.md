# نصب Vscode

## نصب Vscode <a id="install-vscode"></a>

به <https://code.visualstudio.com/download> بروید

دانلود و نصب کنید

## نصب افزونه‌ها <a id="install-extensions"></a>

هنگام نخستین باز کردن این پروژه، از شما خواسته می‌شود افزونه‌های پیشنهادی
workspace را نصب کنید. روی `Install` کلیک کنید.

اگر این مرحله را نمی‌بینید:

`Ctrl+Shift+P` را بزنید.

`Extensions: Show Recommended Extensions` را تایپ کنید و `Enter` را بزنید.

افزونه‌های پیشنهادی نمایش داده می‌شوند.

مطمئن شوید که همهٔ افزونه‌های پیشنهادی نصب شده‌اند.
