# DNA Guides Guide

- Create a new guide as a .md file in `dna/doc/en/guides`
- Ship every guide in every language: translate it into the same file
  name in `dna/doc/de/guides` and `dna/doc/fa/guides`, and change all
  languages in the same commit
- Keep the tags of the sections the same in every language
- Write a guide short and concise, as token-saving as possible
- Write with clear instructions, addressing the reader directly,
  like a cookbook
- Where useful, reference other guides; avoid duplicating content
